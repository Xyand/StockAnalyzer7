How much of each fund we could see

Free data feeds publish only a fund's ten largest positions — often a third of a broad index fund. Everything beyond that is reported as undisclosed rather than guessed at. To get to 100%, download the fund's own holdings file from the issuer and add it below.

Issuers publish these free: iShares and SPDR link a “Holdings” CSV on each fund page; Vanguard offers one under “Portfolio & Management”. Any file with a name or ticker column and a weight column will parse.
